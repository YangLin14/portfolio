PromptGuard

A prompt-injection testing tool I built during my Ubitus internship on top of utkusen's open-source promptmap. A target LLM is attacked, a controller LLM judges each result, and an Improver LLM reads the failures and proposes a hardened system prompt.

What I added

1. Improver LLM loop

  • After a system prompt fails an attack test, the Improver LLM reads the failed cases and rewrites the prompt

2. Modular Python package

  • Refactored the scanner from a script into a Python package

3. UbiGPT provider

  • Added provider support for UbiGPT, the company LLM, next to the existing backends

4. Override-rule category

  • Added an override-rule category; the rule set spans 7 categories and 50+ rules

Use at Ubitus

I used PromptGuard to harden the system prompts across 5 internal LLM products.
