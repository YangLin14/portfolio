SO-101 Visual RL Arm

A personal project to get visual reinforcement learning running on a real robot arm. I set up an SO-101 leader/follower pair at home and forked Squint, a fast visual Soft Actor-Critic method from UC San Diego that trains manipulation policies in simulation in minutes, to train on the UCSD SDSC cluster and deploy on my own arm.

What I've done

1. Hardware setup

  • 🦾 Configured motor IDs for both arms (6 Feetech servos each, 1 Mbps): a 5V leader with mixed gear ratios and a 12V follower with 1/345 servos
  • 🔌 Mapped each arm to its control board's serial-number port name, which stays fixed as long as the board does

2. Calibration and teleop

  • 🎛️ Calibrated both arms with LeRobot and matched the follower's calibration id to the deploy config
  • 🕹️ Leader–follower teleoperation working on macOS

3. Training setup

  • 🖥️ Workflow split: Squint training in simulation on the SDSC cluster, teleop and deployment on the Mac the arm is plugged into
  • 📝 A setup log (ports, motor table, calibration steps, commands) so the arm can be rebuilt from scratch

About Squint

Squint (Almuzairee and Christensen, IEEE RA-L 2026) reaches fast wall-clock training through image preprocessing, architecture choices, and hyperparameters that let SAC use many parallel environments and reuse experience well. It ships eight SO-101 tasks in ManiSkill: reach, lift, place, and stack, each with a cube or a can, plus a sim-to-real deploy script for a wrist camera.

Status

In progress. The arms are set up and teleoperating. Next is training the Squint tasks on the cluster and deploying them sim-to-real on my follower arm. No results of my own yet.
